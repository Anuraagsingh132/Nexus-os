# Design System

Visual direction: calm, dense when useful, modern, and credible—charcoal/neutral surfaces with an indigo-violet brand accent, restrained gradients, clear borders, and high information hierarchy. Support light, dark, and system themes.

Define tokens for color, typography, spacing, radii, elevation, motion, focus, status, chart colors, and z-index. Use Inter or a system-compatible sans face and a monospace stack for code. Components must use tokens rather than arbitrary values.

Build accessible primitives: buttons, links, inputs, comboboxes, dialogs, drawers, menus, tabs, data tables, cards, avatars, badges, tooltips, toasts, skeletons, date pickers, rich editor surfaces, kanban cards, file tiles, charts, and permission selectors.

Motion lasts roughly 120–240 ms, respects reduced-motion settings, and clarifies state rather than decorating every action. Loading uses skeletons for known shapes and progress for long ingestion/upload jobs.
