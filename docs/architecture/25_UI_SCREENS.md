# UI Screens

Public: landing, sign up, login, verify email, forgot/reset password, OAuth result, MFA, invitation acceptance.

Onboarding: profile, create/join organization, workspace setup, invite team, first project.

Authenticated: home dashboard; inbox/notifications; search; AI assistant; workspace member/settings; project overview; task board/list/timeline/calendar and task detail; channels/DM/thread; documents list/editor/history; files/folders/preview/versions; calendar/event/meeting; analytics; profile/preferences/sessions; admin users/audit/usage/flags/integrations.

Each screen specifies loading, empty, partial, offline, error, forbidden, and mobile states during implementation. Use shareable URLs for selected projects/tasks/channels/docs/files where permissions allow.
