# Documentation

Required living docs:

- Root README with value proposition, screenshots, features, architecture, prerequisites, one-command local setup, demo credentials, test/build commands, and troubleshooting.
- Architecture diagrams and ADRs.
- Generated OpenAPI plus authentication, pagination, errors, idempotency, WebSocket events and examples.
- Database migration/schema guide.
- AI/RAG ingestion, provider, safety and evaluation guide.
- Security threat model and operational runbooks.
- Deployment/environment/backup/restore/rollback guides.
- Test report, known limitations, roadmap, and contribution guide.

Documentation must match actual commands and implementation. CI may validate links, OpenAPI generation, and environment-variable references.
