# Engineering Checklist

- [ ] All blueprint files read and traced to tasks.
- [ ] Architecture and security decisions recorded.
- [ ] Local stack, migrations, seed and health checks work.
- [ ] P0 vertical slices include UI, API, auth, persistence, tests and docs.
- [ ] Cross-tenant and role-escalation tests pass.
- [ ] Upload and AI safety controls are present.
- [ ] OpenAPI and typed client are current.
- [ ] Realtime reconnect and authorization are tested.
- [ ] Builds, lint, format, unit, integration and E2E pass.
- [ ] Accessibility and responsive checks pass.
- [ ] Performance queries/budgets are measured.
- [ ] Logs, metrics, traces, dashboards and runbooks exist.
- [ ] CI, images, deployment, migration, backup and rollback are documented.
- [ ] No secrets, dead controls, stale TODOs, fake results or known P0 defects.
- [ ] Final report distinguishes implemented, limited, deferred, and human-only actions.
