# Project Roadmap

1. Foundation: monorepo, Compose, CI, database/migrations, design shell, observability.
2. Identity and tenancy: auth, sessions, organizations, workspaces, invitations, RBAC, audit.
3. Work core: projects, tasks, board/list, comments, labels, files, activity.
4. Collaboration: channels, DMs, realtime, threads, reads, notifications.
5. Knowledge: documents, file manager, search, ingestion, cited RAG.
6. Coordination: meetings, calendar, reminders, dashboards, admin.
7. Hardening: security, accessibility, performance, PWA, E2E, runbooks and deployment.
8. Expansion: P1 features, then explicitly approved P2 integrations.

Each phase exits only with migrations, authorization, tests, docs, seed fixtures and a runnable demonstration.
