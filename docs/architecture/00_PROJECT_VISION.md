# Project Vision

Nexus OS is the shared operating system for student teams, startups, and growing companies. It replaces fragmented context across chat, tasks, documents, files, calendars, and AI tools with one permission-aware workspace.

## Product promise

A member can move from conversation to decision to task to document without losing context. The AI assistant can answer questions only from knowledge the requester is allowed to access and provides citations back to source material.

## Target users

- Student teams managing projects and placements.
- Startup teams of 3–100 people.
- Departments needing a self-contained collaboration hub.
- Workspace owners and administrators managing access, security, and usage.

## Differentiators

- One consistent organization/workspace/project permission model.
- Chat, tasks, docs, files, meetings, and AI are linked rather than siloed.
- Workspace-grounded AI with traceable citations.
- Java/Spring architecture demonstrating employable backend and system-design skills.
- Local-first developer experience with replaceable cloud adapters.

## Non-goals for first production release

Nexus OS is not a replacement for native Zoom media transport, a full Git hosting provider, a payroll system, or a no-code platform. Video meetings use integration links. Billing may be metered and admin-visible before real payment settlement is enabled.
