# Accessibility

Target WCAG 2.2 AA. All flows support keyboard navigation, visible focus, semantic landmarks, logical headings, accessible names/descriptions, skip links, sufficient contrast, zoom/reflow, reduced motion, and screen-reader announcements for async changes.

Kanban drag/drop must have keyboard alternatives. Charts include summaries/tables. Editors expose formatting controls and document structure. Dialog focus is trapped/restored. Toasts use appropriate live regions. Error messages identify fields and recovery.

Run automated axe checks plus manual keyboard and screen-reader-oriented checks on auth, shell, tasks, chat, files, editor, AI, admin, and settings.
