# Monitoring and Logging

Emit structured JSON logs with timestamp, level, service, environment, request/trace ID, safe actor ID, workspace ID, event, latency, and outcome. Never log secrets or full sensitive bodies.

Expose RED metrics for APIs, WebSocket connections/events, DB pools, cache hit rate, outbox lag, Kafka lag, upload/ingestion duration and failures, search latency, LLM tokens/cost/latency, citation rate, and authorization denials. Use distributed traces across web, API, workers, storage and AI calls.

Create example dashboards and alerts for availability, p95 latency, 5xx rate, login abuse, queue lag, failed ingestion, DB saturation, storage errors, AI spend anomaly, and cross-tenant/security signals. Include runbooks and alert ownership.
