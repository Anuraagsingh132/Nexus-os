# Feature Specifications

## Workspace and projects

Create organizations, teams/workspaces, invitations, member management, role assignment, settings, archive/export flows, and unlimited projects subject to configured plan limits. Project home links tasks, files, docs, chat, meetings, calendar, and analytics.

## Tasks

Board and list are P0; timeline/calendar are P1. Tasks support status, priority, assignees, labels, dates, subtasks, dependencies, recurrence, time tracking, attachments, comments, activity, and stable drag ordering. Validate cycles in dependencies and recurrence limits.

## Chat

Public/private channels, DMs, threads, reactions, typing, presence, read state, pins, mentions, file sharing, edits/deletes, cursor history, and search. Voice messages are normal secured audio files with waveform metadata; calls are external meeting links.

## Documents and files

Block-capable Markdown editor with headings, lists, tables, code, mentions, comments, templates, AI assist, autosave, optimistic concurrency, versions and restore. Files support folders, drag/drop, multipart upload, safe preview, versioning, ACLs, quotas, checksums, and malware-scan status.

## Calendar and notifications

Tasks, deadlines, events, meetings and reminders share a workspace calendar. Notification channels are in-app P0, email adapter P1, web push P1. Users control preferences, quiet hours, batching, and mention exceptions.

## Dashboard/admin

Show real database-backed project completion, workload, velocity, burndown, activity, storage, member usage, and AI insights with clear time ranges. Admin covers users, roles, audit logs, feature flags, integrations, reports, storage, and usage—not fake billing.
