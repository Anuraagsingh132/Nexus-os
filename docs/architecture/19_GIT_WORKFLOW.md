# Git Workflow

Use short-lived feature branches when possible and Conventional Commits such as `feat(tasks): add authorized board reorder`. Commit only green coherent milestones. Never commit `.env`, secrets, generated uploads, database data, IDE files, or large test artifacts.

Pull requests/templates should include scope, screenshots where useful, migrations, security/permission impact, tests, docs, rollout and rollback. Protect main with required checks. Antigravity must not force-push, publish, merge, or discard unknown work without authorization.
